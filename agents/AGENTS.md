# Global instructions

Codex と OpenCode の両方から読み込まれる共通のグローバル指示。

## 応答

- 常に日本語で応答する。技術用語・識別子（ツール名、パッケージ名、コード）は英語のまま。

## ツール活用

- 既存ファイルを編集する前に対象を読む。新規作成時は配置先と関連する既存の例を確認する。推測でコードや設定を書かない。
- 探索はリッチな検索ツールを優先する: ripgrep (`rg`) や組み込みの grep / glob を使い、`cat` や `find` の乱用を避ける。
- 検索で候補を絞り込み、変更に関係する実装・呼び出し元・テストを必要に応じて確認する。
- 独立した複数の調査は、直列ではなく並列で実行する。
- 依頼に必要な編集・生成・検証は行う。破壊的な操作はユーザーの明示的な承認なしに実行しない。
- `home-manager switch`、`nixos-rebuild switch`、`sudo` は実行しない。コマンドを提案して、ユーザー自身に実行してもらう。

## 作業スタイル

- 必要な修正と検証を含めて変更範囲を絞り、周辺コードのスタイル・命名・構成に合わせる。
- プロジェクト固有の指示に従い、変更に関連する既存テストや静的解析を確認して実行する。必要に応じて回帰テストを追加する。実行できない場合は理由と未検証の範囲を報告する。
- 依頼されていないリファクタリングや「おまけ」の変更を加えない。
- 情報が不足している場合は捏造せず、ツールで収集するか、不明であることを伝える。
